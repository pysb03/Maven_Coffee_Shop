# ☕ Maven Coffee Shop

Transaction records for Maven Roasters, a fictitious coffee shop operating across three NYC locations. The dataset contains transaction dates, Category of Product, Product Type, timestamps, store locations, and product-level details.

## Project Objective

Analyze sales performance and customer purchasing patterns to identify trends in revenue, Month-over-month (MoM), transaction volume, product performance, and store activity.

## Recommended Analysis

- How have Maven Roasters' sales trended over time?
- Which days of the week tend to be busiest, and why might that be the case?
- What times of day tend to be most popular? Does the same trend hold across all locations?
- Which products are sold most and least often?
- Which products generate the most revenue for the business?
- How does sales performance differ across store locations?

## Key Analysis

The analysis focuses on:

- Sales and revenue trends over time (by Hour, Weekday, and Month)
- Transaction volume by day of week
- Transaction volume by hour of day
- Store-level performance (Top Transaction & Top Revenue)
- Product sales volume
- Product revenue contribution
- Customer purchasing patterns

## Dataset

The dataset includes:

- Transaction ID
- Transaction Date
- Transaction Time
- Transaction Quantity
- Store ID
- Store Location
- Product ID
- Unit Price
- Product Category
- Product Type
- Product Detail

## Dashboard

The analysis is presented through Excel Dashboard and Power BI Dashboard
